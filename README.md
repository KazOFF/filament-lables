# Filament Labels

Angular PWA для создания и печати этикеток филамента. Главная страница — неизменяемый каталог из 598 цветовых профилей Bambu Lab, Creality, eSUN, SUNLU, REC, Bestfilament, FDplast и Filamentarno!; доступны SVG-предпросмотр, быстрая печать из карточки, экспорт SVG/PNG/PDF и раскладка на A4.

## Запуск

Требуется поддерживаемая Angular версия Node.js (рекомендуется Node 24 LTS).

```bash
npm install
npm start
```

Откройте `http://localhost:4200`. Каталог загружается из встроенного JSON, а пользовательские значения редактора существуют только в текущем сеансе и не сохраняются.

## Команды

```bash
npm run build
```

Production-сборка создаётся в `dist/filament-labels/browser`. Для установки как PWA её нужно раздавать по HTTPS (либо с `localhost`).

## Данные и печать

- Встроенные профили производителей доступны только для чтения и не изменяются из интерфейса.
- Официальный пятизначный код показывается у цветов Bambu Lab. Для остальных брендов код остаётся пустым, если производитель его не публикует.
- Не опубликованные производителем параметры печати не подменяются типовыми значениями и не показываются на карточке или этикетке.
- HEX сторонних брендов служит визуальным ориентиром по официальным карточкам товара, а не колориметрическим значением производителя.
- Для собственной этикетки используйте временный редактор пользовательских значений.
- Пунктирную линию обрезки можно включать и выключать в редакторе и окне быстрой печати; настройка применяется ко всем форматам экспорта.
- Для отдельной этикетки и общего листа доступна цветная или чёрно-белая печать. В ч/б режиме цветная полоса и маркер скрываются, а загруженный логотип выводится в оттенках серого.
- Разные каталожные и пользовательские этикетки можно собрать в очередь, задать количество копий и вывести общим листом A4 в PDF или системный диалог печати.
- В окне общего листа отображается живой предпросмотр выбранной этикетки; щелчок по строке очереди переключает образец.
- PDF использует встроенный Noto Sans с поддержкой кириллицы; файлы шрифта и лицензия OFL находятся в `public/fonts`.
- Каталожные этикетки используют встроенные цветные и монохромные брендовые SVG из `public/brands`.
- На компактных этикетках геометрия и типографика масштабируются раздельно: текст уменьшается мягче, а длинные названия серий дополнительно вписываются по ширине.
- Для точного физического размера при печати PDF используйте масштаб 100% и отключите автоматическое вписывание в страницу.
- Список файлов задаётся в `public/data/catalog-manifest.json`; каталоги производителей находятся рядом. Общие параметры задаются на уровне линейки, цвета — в массиве `colors`.
- Технический источник и ссылка на покупку в России сохраняются отдельно. Ошибка одного файла показывает предупреждение, но не блокирует остальные каталоги.
